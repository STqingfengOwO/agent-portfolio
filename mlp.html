01 / 任务

要解决什么，用什么设置

XOR 的四个样本中，(0,1) 和 (1,0) 输出 1，(0,0) 和 (1,1) 输出 0。它们在平面上交错排列，一条直线分不开，所以单层感知器做不到；加一个隐藏层，把输入先变成中间特征，输出层再用一条直线就能分开。

Structure
2 → 2 → 1
两个 sigmoid 隐藏单元
Loss
二元交叉熵
直接作用在 logits 上
Optimizer
Adam · lr = 0.03
β₁ 0.9 / β₂ 0.999
Training
300 轮 · 整批
4 个样本一起更新一次

可学习的参数一共 9 个：输入到隐藏层的权重 W（2×2）、隐藏层偏置 b（2 个）、隐藏层到输出的权重 v（2 个）、输出偏置 bout（1 个）。初值沿用课堂代码里的设定，所以每次打开看到的过程是一样的。

必须坦白：这些不是「训练出来的最优解」，而是从一组人为设定的初值出发，用梯度下降一点点改出来的结果。下面每一张图都对应真实的参数更新，不是预先画好的示意。

03 / 解读

这些参数各自在做什么

训练完成后回头看，每个参数的变化都能对上它在网络里的角色。

W · 输入 → 隐藏

两个隐藏单元分工

W 的四条连接让 h₁ 主要对「x₁=1 且 x₂=0」敏感，h₂ 主要对「x₁=0 且 x₂=1」敏感。两个单元各负责一个正类样本，XOR 就被拆成了两个可以相加的条件。

b · 偏置

控制单元何时被激活

隐藏层偏置把 sigmoid 的转折点挪开。偏置太正会让单元对任何输入都接近 1，太负则一直沉默；训练就是在找合适的「门槛」。

v · 隐藏 → 输出

把两个条件合成一个判断

输出层只是把 h₁、h₂ 加权相加再做一次 sigmoid。它的作用是「或」：任意一个隐藏单元被激活，就判为 1，所以 v 最后通常都为正。

另一个能直接看到的现象是学习率的影响。同样 300 轮，学习率太小走不完，太大则会来回震荡。下表是同一份代码、同一组初值、只改学习率的结果：

04 / 实现

训练和可视化的代码

这页的可视化本身用 JavaScript 实现（浏览器里直接训练），下面是等价的 NumPy 版本，逻辑完全一致：手动前向、手动反向传播、Adam 更新，再用 matplotlib 画图。

① NumPy：手写前向 / 反向 / Adam

mlp_xor.py 
# 2-2-1 MLP 学习 XOR：不用框架，手动实现反向传播
import numpy as np

X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
t = np.array([[0.], [1.], [1.], [0.]])

W  = np.array([[2., -2.], [-2., 2.]])   # 2 输入 → 2 隐藏
b  = np.array([-1., -1.])
v  = np.array([[3.], [3.]])             # 2 隐藏 → 1 输出
bo = np.array([-2.5])
params = [W, b, v, bo]

m = [np.zeros_like(p) for p in params]  # Adam 一阶矩
s = [np.zeros_like(p) for p in params]  # Adam 二阶矩
lr, b1, b2, eps = 0.03, 0.9, 0.999, 1e-7

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

history = {"loss": [], "W": [], "v": []}

for epoch in range(1, 301):
    h = sigmoid(X @ W + b)              # (4, 2)
    logit = h @ v + bo                  # (4, 1)
    p = sigmoid(logit)

    # 二元交叉熵（在 logits 上算，数值更稳）
    loss = np.mean(np.maximum(logit, 0) - logit * t
                   + np.log1p(np.exp(-np.abs(logit))))

    # 反向传播：链式法则逐层求导
    dlogit = (p - t) / len(X)           # (4, 1)
    gv  = h.T @ dlogit                  # (2, 1)
    gbo = dlogit.sum(axis=0)
    dpre = (dlogit @ v.T) * h * (1 - h) # (4, 2) 经过 sigmoid 的导数
    gW = X.T @ dpre                     # (2, 2)
    gb = dpre.sum(axis=0)               # (2,)

    # Adam 更新
    for i, (param, g) in enumerate(zip(params, [gW, gb, gv, gbo])):
        m[i] = b1 * m[i] + (1 - b1) * g
        s[i] = b2 * s[i] + (1 - b2) * g * g
        m_hat = m[i] / (1 - b1 ** epoch)
        s_hat = s[i] / (1 - b2 ** epoch)
        param -= lr * m_hat / (np.sqrt(s_hat) + eps)

    history["loss"].append(loss)
    history["W"].append(W.copy())
    history["v"].append(v.copy())

print("预测:", (p.ravel() >= 0.5).astype(int).tolist())
print("W =\n", np.round(W, 3))
print("b =", np.round(b, 3), " v =", np.round(v.ravel(), 3),
      " b_out =", round(float(bo), 3))

② matplotlib：把学习参数画出来

mlp_visualize.py 
import matplotlib.pyplot as plt

fig, ax = plt.subplots(2, 2, figsize=(10, 7.5))

# 1. 损失曲线
ax[0, 0].semilogy(history["loss"])
ax[0, 0].set_title("loss")
ax[0, 0].set_xlabel("epoch")

# 2. 决策边界：在输入平面撒网格，逐个算概率
gx, gy = np.meshgrid(np.linspace(-0.2, 1.2, 120),
                     np.linspace(-0.2, 1.2, 120))
grid = np.stack([gx.ravel(), gy.ravel()], axis=1)
prob = sigmoid(sigmoid(grid @ W + b) @ v + bo).reshape(gx.shape)
ax[0, 1].contourf(gx, gy, prob, levels=20, cmap="coolwarm", alpha=.75)
ax[0, 1].scatter(X[:, 0], X[:, 1], c=t.ravel(),
                 cmap="coolwarm", edgecolor="k", s=90)
ax[0, 1].set_title("decision boundary")

# 3. 隐藏层表示
H = sigmoid(X @ W + b)
ax[1, 0].scatter(H[:, 0], H[:, 1], c=t.ravel(),
                 cmap="coolwarm", edgecolor="k", s=90)
ax[1, 0].set_title("hidden space (h1, h2)")
ax[1, 0].set_xlim(-0.05, 1.05); ax[1, 0].set_ylim(-0.05, 1.05)

# 4. 权重轨迹
Wh = np.array(history["W"])   # (300, 2, 2)
Vh = np.array(history["v"])   # (300, 2, 1)
for i in range(2):
    for j in range(2):
        ax[1, 1].plot(Wh[:, i, j], label=f"W{i+1}{j+1}")
for j in range(2):
    ax[1, 1].plot(Vh[:, j, 0], "--", label=f"v{j+1}")
ax[1, 1].set_title("weights over epochs")
ax[1, 1].legend(fontsize=7, ncol=2)

plt.tight_layout()
plt.savefig("mlp_params.png", dpi=150)

05 / 结论

做完之后记住的三件事

1. 学习参数不是「猜」出来的。每一步更新的方向由损失对参数的梯度决定，Adam 只是让步长更稳一些。关掉梯度、只保留前向计算，参数就永远不会变。

2. 隐藏层的作用是换一组坐标。原始平面上 XOR 两类点交错，任何直线都分不开；经过 W 和 b 映射到 (h₁, h₂) 后，同样的样本变成线性可分，输出层才只需要画一条直线。

3. 超参数会改变过程，不改变结论。学习率小收敛慢，学习率大会震荡，但在合理范围里，300 轮都能学会 XOR。真正决定能力边界的是网络有没有隐藏层，而不是训练多久。
