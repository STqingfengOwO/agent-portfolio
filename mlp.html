01 / 背景与故事

两扇门、两位门卫、一盏灯

这一节要弄明白的是一件事：为什么单层网络做不对 XOR，加了隐藏层之后为什么就对了。只有 4 个数据点，可以自己在纸上画。

XOR 是什么，为什么拿它当作业

XOR 的规则是：两个输入不一样时输出 1，一样时输出 0。作业里就这 4 条：

  • ①x₁ = 0，x₂ = 0，输出 0
  • ②x₁ = 0，x₂ = 1，输出 1
  • ③x₁ = 1，x₂ = 0，输出 1
  • ④x₁ = 1，x₂ = 1，输出 0

拿它当作业，不是因为它能解决什么实际问题，而是因为它是能说明「一条直线不够用」的最小例子。前面课上的单层感知机只会画一条直线，碰到这 4 个点，怎么画都会错两个。这件事你在纸上就能验证，不用信结论。

所以这一节真正要学的不是这 4 个答案，而是两件事：为什么一条直线一定分不开；隐藏层做了什么，让原来分不开的点变得能分开。后面的调参数、七步计算、训练过程，都是在回答这两个问题。

换个说法：两扇门和一盏灯

左边一扇门 x₁，右边一扇门 x₂，开着记 1，关着记 0。屋里有一盏灯，亮记 1，灭记 0。规则是：只有一扇门开着时灯才亮；两扇都关、两扇都开，灯都不亮。这就是 XOR。

门口站两个门卫。甲管「左门开、右门关」，乙管「左门关、右门开」。看到自己管的情况就举手。灯不看别的，只要有人举手就亮。这就是隐藏层和输出层在做的事，后面会一个个对应上。

为什么一条直线不够

在纸上画坐标轴，横轴 x₁、纵轴 x₂，4 个样本就是 4 个角：左下 (0,0) 和右上 (1,1) 输出 0，左上 (0,1) 和右下 (1,0) 输出 1。

现在用尺子画一条直线，要求输出 0 的两个点在一侧、输出 1 的两个点在另一侧。画不出来。输出 0 的两个点在对角，输出 1 的两个点也在对角，直线无论怎么斜，两边都会各有一个 0 和一个 1。

两个门卫就是把这个要求拆开：甲只判断「是不是 (0,1) 附近」，乙只判断「是不是 (1,0) 附近」。这两个判断各用一条线就能做。最后灯把两个结果合起来，任意一个成立就亮。

为了什么

单层网络过不去

通俗版

单层网络只能画一条直线，XOR 是第一个它一定画错的题。弄懂这道题，才知道隐藏层是干什么用的，而不是只记住「多层更强」。

严谨版

XOR 是线性不可分的布尔函数，任何单层线性模型都无法零误差拟合。把它作为最小基准，可以检验模型是否具备至少一层非线性特征变换能力。

为什么可以

先把问题拆成两个小判断

通俗版

隐藏层把「4 个点分两边」拆成两个小判断：一个单元认 (0,1)，一个单元认 (1,0)。每个小判断用一条直线就能完成，输出层再把两个结果合起来。

严谨版

隐藏层计算 h = σ(Wx + b)，把输入映射到新的特征空间。只要隐藏单元足够，这个映射可以把 XOR 的四个样本送到线性可分的位置，输出层只需在新空间里确定一个线性判别面。

怎么做

反复算错、反复改参数

通俗版

参数一开始是随便给的，预测基本是错的。程序先算错多少，再算每个参数该往哪边改一点，改完再算一遍。这样重复 300 次，参数就慢慢改到了能分对的位置。

严谨版

前向传播得到 logits 与概率；以二元交叉熵为损失；反向传播用链式法则求各参数偏导；Adam 依据一阶、二阶矩估计做自适应步长更新。整批 4 个样本每轮更新一次。

06 / 参数解读

训练完回头看，每个参数在干什么

结合第 05 节的参数表和六张图，这 9 个数可以分成三组来理解。

W · 输入 → 隐藏

两个门卫的分工

通俗版

W 的四条连接让 h₁ 主要对「左门开、右门关」有反应，h₂ 主要对「左门关、右门开」有反应。两个单元各负责一个正类样本，XOR 就被拆成了两个能相加的条件。

严谨版

W 的两列分别决定两个隐藏单元的输入方向。训练后两列近似为 (w, −w) 与 (−w, w)，使 h₁、h₂ 分别对两个正类样本响应，负类样本则被两个单元同时压低。

b · 隐藏层偏置

决定门卫何时举手

通俗版

偏置把 sigmoid 的转折点挪开。太正，门卫见谁都举手；太负，一直沉默。训练就是在找合适的门槛，让「该举手时才举手」。

严谨版

b 控制隐藏单元激活的阈值位置。它和 W 一起决定 sigmoid 在输入空间中的平移，从而调整每个单元对样本的响应区间。

v · 隐藏 → 输出

把两个条件合成一个判断

通俗版

输出层只是把 h₁、h₂ 加权相加，再做一次 sigmoid。它做的是「或」：任意一个门卫举手，灯就亮。所以 v 最后都是正的。

严谨版

输出层在隐藏空间中定义线性判别面 v₁h₁ + v₂h₂ + b_out = 0。由于两个隐藏单元分别对应两个正类，v 取正值相当于对二者的响应做逻辑或。

回到第 05 节的参数表：W 的四个值最后约为 ±6，v 约为 8.2，b 与 b_out 约为 −3.5 / −4.0。这些数值本身没有唯一标准——换一组初值，最后可能得到另一组数，但只要隐藏层的两个单元形成这种「各认一边」的分工，XOR 就能被分开。

08 / 实现

训练和可视化的代码

这页的可视化本身用 JavaScript 实现（浏览器里直接训练），下面是等价的 NumPy 版本，逻辑完全一致：手动前向、手动反向传播、Adam 更新，再用 matplotlib 画图。

① NumPy：手写前向 / 反向 / Adam

mlp_xor.py 
# 2-2-1 MLP 学习 XOR：不用框架，手动实现反向传播
import numpy as np

X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
t = np.array([[0.], [1.], [1.], [0.]])

W  = np.array([[2., -2.], [-2., 2.]])   # 2 输入 → 2 隐藏
b  = np.array([-1., -1.])
v  = np.array([[3.], [3.]])             # 2 隐藏 → 1 输出
bo = np.array([-2.5])
params = [W, b, v, bo]

m = [np.zeros_like(p) for p in params]  # Adam 一阶矩
s = [np.zeros_like(p) for p in params]  # Adam 二阶矩
lr, b1, b2, eps = 0.03, 0.9, 0.999, 1e-7

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

history = {"loss": [], "W": [], "v": []}

for epoch in range(1, 301):
    h = sigmoid(X @ W + b)              # (4, 2)
    logit = h @ v + bo                  # (4, 1)
    p = sigmoid(logit)

    # 二元交叉熵（在 logits 上算，数值更稳）
    loss = np.mean(np.maximum(logit, 0) - logit * t
                   + np.log1p(np.exp(-np.abs(logit))))

    # 反向传播：链式法则逐层求导
    dlogit = (p - t) / len(X)           # (4, 1)
    gv  = h.T @ dlogit                  # (2, 1)
    gbo = dlogit.sum(axis=0)
    dpre = (dlogit @ v.T) * h * (1 - h) # (4, 2) 经过 sigmoid 的导数
    gW = X.T @ dpre                     # (2, 2)
    gb = dpre.sum(axis=0)               # (2,)

    # Adam 更新
    for i, (param, g) in enumerate(zip(params, [gW, gb, gv, gbo])):
        m[i] = b1 * m[i] + (1 - b1) * g
        s[i] = b2 * s[i] + (1 - b2) * g * g
        m_hat = m[i] / (1 - b1 ** epoch)
        s_hat = s[i] / (1 - b2 ** epoch)
        param -= lr * m_hat / (np.sqrt(s_hat) + eps)

    history["loss"].append(loss)
    history["W"].append(W.copy())
    history["v"].append(v.copy())

print("预测:", (p.ravel() >= 0.5).astype(int).tolist())
print("W =\n", np.round(W, 3))
print("b =", np.round(b, 3), " v =", np.round(v.ravel(), 3),
      " b_out =", round(float(bo), 3))

页面上那 6 张图就是按上面的思路画的：损失曲线对应第 ① 段，决策边界和隐藏层表示对应第 ②③ 段，参数轨迹对应最后一段。区别只在绘制方式——这里是 canvas，Python 版用 matplotlib。

收尾

做完之后记住的三件事

1. 参数不是猜出来的。每一步的方向由损失对参数的梯度决定，Adam 只是让步长更稳。没有反向传播，参数永远不会变。

2. 隐藏层的作用是换坐标。原始平面上 XOR 两类点交错，任何直线都分不开；映射到 (h₁, h₂) 后变得线性可分，输出层才只需要画一条直线。

3. 超参数改变过程，不改变结论。学习率小收敛慢，大了步子更猛；合理范围内 300 轮都能判对，但 loss 差得很远。真正决定能力边界的是有没有隐藏层。
